## 规则

1. 服务端先于客户端发布；服务端保留至少一个旧版兼容窗口。
2. 契约版本变化必须同时更新 `artifact_meta.json.contract_version` 与本文档。
3. 旧壳加载新产物：`min_bridge_version` 不满足时提示"请升级应用"，不白屏。
4. 新壳加载旧产物：保持可用，缺失能力按 `capability_matrix.md` 降级。

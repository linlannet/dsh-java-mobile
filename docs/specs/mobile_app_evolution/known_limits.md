# 已知限制与发布说明

## 能力限制

1. **移动端不内嵌 Agent**：iOS 禁止子进程且无 JVM；Android 端侧内嵌仅实验。移动端通过近场/云侧连接已运行的 Agent。
2. **移动端无 Git 能力**：`git` 能力域在 Android/iOS/HarmonyOS 为 `NONE`，相关入口隐藏。
3. **Android/iOS 更新为提示跳商店**：不做应用内静默更新。
4. **HarmonyOS 文件能力降级**：文件选择/导出经 ArkWeb 桥，超大文件受限。
5. **小程序能力受限**：仅 HTTPS、无安全存储、诊断精简。
6. **明文传输限制**：公网必须 HTTPS；仅回环/局域网可在显式确认后使用明文。

## 平台限制

- Android/iOS 使用 Tauri 2 Mobile；HarmonyOS 使用独立 ArkTS/ArkUI + ArkWeb 壳。
- 三端共享同一份 H5 产物，壳层差异化，禁止 fork UI。

## 待决策事项

- SSH 端口转发、Relay 中继、扫码实现需重新选型（旧 KMP 参考实现已删除）。
- 小程序是否纳入首版发布范围。

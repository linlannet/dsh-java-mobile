# 商店合规与隐私物料

## 隐私政策必备条目

1. 收集的数据类型：设备标识（服务端签发）、连接配置、崩溃与诊断信息。
2. 数据用途：设备配对、连接鉴权、故障排查。
3. 数据存储：本地安全存储（凭据仅存引用/摘要），不写入明文。
4. 数据共享：不上传对话正文；诊断导出前脱敏。
5. 用户权利：可删除设备、吊销凭据、清除本地配置。

## 权限用途说明

| 权限 | 用途 | 拒绝后行为 |
| --- | --- | --- |
| 网络 | 连接 Agent | 无法使用 |
| 相机（扫码） | 扫描配对码 | 可改用手输短码 |
| 通知 | 任务完成提醒 | 仅无提醒 |
| 文件读写 | 选择/导出文件 | 相关入口置灰 |

## 审核说明要点

- 应用内使用 WebView 承载自有 H5 产物，**不加载远程可执行脚本**，无热更新。
- 不包含应用内支付、不收集通讯录/位置。
- 配对码 10 分钟一次性有效，服务端可吊销设备。
- 内容由用户自建 Agent 产生，应用提供举报/退出入口（按平台要求）。

## 物料清单

- 隐私政策 URL
- 权限用途文案（中英文）
- 应用截图（手机/平板）
- 应用图标（各尺寸）
- 审核账号与测试配对码（如需）
- 版本说明

## 合规检查

- [ ] 隐私政策覆盖全部收集项
- [ ] 权限仅在首次使用时申请
- [ ] 拒绝权限不崩溃、有降级路径
- [ ] 无远程脚本与热更新
- [ ] 诊断导出已脱敏
- [ ] 设备吊销可即时生效
